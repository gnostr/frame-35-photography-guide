# FRAME / 35 — Photography Field Guide

**Light first. Scene second. Look last.**  
**先看光线，再选场景，最后确定风格。**

FRAME / 35 is a lightweight, browser-based photography reference and recommendation guide. It helps photographers move from shooting conditions to a specific film stock, Leica LUX look, or VSCO Pro preset, with practical exposure and metering references.

FRAME / 35 是一个轻量级的网页摄影参考与推荐工具。它帮助摄影者从现场光线和拍摄场景出发，选择具体胶片、Leica LUX Look 或 VSCO Pro Preset，并提供曝光与测光参考。

## English

### Features

- **Four-step recommendation flow**
  1. Light conditions
  2. Subject and shooting scene
  3. Desired visual effect
  4. Creative medium: compare all, film, Leica LUX Pro, or VSCO Pro

- **Film reference library**  
  Includes the 24 film entries specified for this project, covering color negative, slide, cinema negative, and black-and-white film.

- **Leica LUX reference library**  
  Organized into Core Color Looks, Monochrome Looks, Monochrome Colour Filters, Artist Looks, and Special Effects. Lens simulations are treated as a separate category from Looks.

- **VSCO Pro reference library**  
  Focuses on VSCO Pro / Membership preset references. Preset availability and naming may vary by app version, subscription, and region.

- **Exposure and metering guidance**  
  Provides starting-point exposure-compensation and metering suggestions based on selected lighting conditions.

- **Offline-friendly static website**  
  The site is a self-contained HTML file. No server, database, build step, or package installation is required.

### Getting started

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Choose the lighting conditions, shooting scene, desired look, and creative medium.
4. Select **Generate Recommendation** to view suggested options and exposure notes.

### Deploy with GitHub Pages

1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder.
4. Save. GitHub Pages will publish the site at the URL shown in the Pages settings.

Make sure the main HTML file is named `index.html` and is located in the repository root.

### Important notes and limitations

- Recommendations are generated by a lightweight, rule-based matching system. They are guidance, not a guarantee of a particular photographic result.
- Film exposure latitude, color response, and processing behavior depend on the actual film, exposure, processing, scanning, and lab workflow.
- Leica LUX and VSCO references describe styles and preset categories. This project does **not** include Leica's or VSCO's proprietary image-processing algorithms and does not apply their native filters to uploaded photos.
- Leica LUX options and VSCO preset availability can change. Verify names and access in the current apps and subscriptions.
- Some entries in the reference library are retained from the project's requested list. Where processing or product details require confirmation, the site marks them as needing verification rather than assuming a specification.
- Exposure-compensation values are starting points only. Confirm exposure using the camera's meter, histogram/highlight warnings where available, and the actual scene.
- Kodachrome 64 is a historical film stock; its original K-14 processing service is no longer available. Fujifilm PRO 400H is discontinued. Check stock condition and available processing before shooting.

## 中文

### 功能

- **四步摄影推荐流程**
  1. 光线环境
  2. 拍摄主体与场景
  3. 目标视觉效果
  4. 实现方式：全部比较、传统胶片、Leica LUX Pro 或 VSCO Pro

- **胶片资料库**  
  收录本项目指定的 24 个胶片条目，涵盖彩色负片、反转片、电影负片和黑白胶片。

- **Leica LUX 参考资料库**  
  按基础彩色 Looks、黑白 Looks、黑白彩色滤镜、摄影师 Artist Looks 和特殊效果分类。镜头模拟与 Looks 分开管理。

- **VSCO Pro 参考资料库**  
  聚焦 VSCO Pro / Membership 可用预设。预设名称和可用范围可能因 App 版本、订阅权益及地区而变化。

- **曝光与测光参考**  
  根据所选光线环境，提供曝光补偿起点和测光方式建议。

- **可离线运行的静态网页**  
  网站由独立 HTML 文件构成，无需服务器、数据库、构建流程或安装依赖。

请确保主网页文件命名为 `index.html`，并放在仓库根目录。

- 胶片的曝光宽容度、色彩表现和冲洗结果，会受到实际胶片、曝光、冲洗、扫描及实验室流程影响。
